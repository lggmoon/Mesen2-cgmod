# Mesen-cgmod

Mesen is a multi-system emulator (NES, SNES, Game Boy, Game Boy Advance, PC Engine, SMS/Game Gear, WonderSwan) for Windows, Linux and macOS.

add Coolgirl support.

and CoolEmu, a pure emulator mapper.

and Fix some bug of mapper, maby.

## Releases

The latest stable version is available from the [releases on GitHub](https://github.com/lggmoon/Mesen2-cgmod/releases).

## Development Builds

[![Mesen](https://github.com/lggmoon/Mesen2-cgmod/actions/workflows/build.yml/badge.svg)](https://github.com/lggmoon/Mesen2-cgmod/actions/workflows/build.yml)

#### <ins>Native builds</ins> (recommended) ####

These builds don't require .NET to be installed.

* [Windows 10 / 11](empty)
* [Linux x64](empty)  (requires **SDL2**)
* [macOS - Intel](empty)  (requires **SDL2**)
* [macOS - Apple Silicon](empty)  (requires **SDL2**)

#### <ins>.NET builds</ins> ####

These builds require **.NET 8** to be installed (except the Windows 7 build which requires .NET 6).
For Linux and macOS, **SDL2** must also be installed.

* [Windows 7 / 8 (.NET 6)](empty)
* [Linux x64 - AppImage](empty)
* [Linux ARM64](empty)
* [Linux ARM64 - AppImage](empty)
